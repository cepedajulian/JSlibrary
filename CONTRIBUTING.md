# Contribuciones

Gracias por contribuir a `library.js`.

1. Abrí un issue para discutir cambios importantes.
2. Creá una rama con un nombre descriptivo.
3. Escribí pruebas para cambios en la API y ejecutá `npm run check`.
4. Documentá los cambios relevantes en `README.md` y `CHANGELOG.md`.
5. Abrí un Pull Request explicando el problema, la solución y las posibles incompatibilidades.

El código aportado se distribuirá bajo la licencia MIT del proyecto; verificá que tenés los derechos para contribuirlo.
No incluyas contraseñas, tokens, datos personales de usuarios ni código de terceros sin una licencia compatible.
